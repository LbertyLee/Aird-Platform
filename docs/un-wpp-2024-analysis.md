# 联合国 WPP 2024 年度人口数据分析

## 修复原因与适用范围

此前检索返回方法论、结果摘要和发布说明 PDF。这些材料并没有中国和美国 1950—2100 年的完整年度表；模型返回空数组而非解析异常。原指标目录缺少国家人口总量、出生人数、净迁移人数，年份识别也未展开1950起始的完整区间。

分析所选来源包含 `https://population.un.org/wpp/` 的外部检索结果时，系统会关联同一官方站点的 WPP 2024 中方案年度 CSV，不依靠模型从方法论 PDF 猜测数值。来源 ID 和访问检查保持原链路，官方文件 URL、原字段、原数值、原单位及预测情景保存在明细行。

| 指标编码 | 官方字段 | 输出口径 |
| --- | --- | --- |
| population_total | TPopulation1July | 7月1日人口，千人转人 |
| tfr | TFR | 总和生育率，每名妇女子女数；兼容既有目录单位“人” |
| births | Births | 年度活产人数，千人转人 |
| net_migration | NetMigrations | 年度净迁移人数，千人转人，保留负值 |

1950—2023为估计值，2024—2100为中方案预测值。“移民人口”在该链路明确采用净迁移人数，不代表移民存量或迁入总数。其他版本及明确指定的高、低、不变生育或零迁移方案不自动替换为2024中方案。

## 运维

数据库增量迁移仅补充缺少的三个计数指标及别名，保留既有配置。查询区间展开为151年，联合国结构化来源上限20000条；超过上限会标记不完整。按指标、国家和年份检查缺失。旧版分析缓存通过 pipelineVersion=9 失效，需重新生成分析；已有会话不自动改写。

为避免跨境大文件下载影响分析，在 `apps/api` 下运行：

```powershell
python scripts/cache-un-wpp-2024.py
```

可在能访问联合国网站的电脑运行，再把文件复制到服务器 API 容器的 `storage/official-data/WPP2024_Demographic_Indicators_Medium.csv.gz`。Docker Compose 将该目录持久化到 official_data 卷。支持 `OFFICIAL_DATA_CACHE_DIR` 配置目录。文件来自官方站点，SHA256固定为 `286ac36bb1415e2e1ade03acfef0a29f0e4c087e2f78e38c48f50c5df89082bc`，服务读取前校验，不匹配则回退官方网络下载。更新固定校验值前必须重新审核版本与单位。此固定版本文件无需按当前日期更新。

官方网络下载最多尝试两次，每次下载和流解析共同限制60秒；错误保留为不完整结果，不制造0值。已筛选年度数据另有30天缓存，仅完整国家年份与所需指标才写入缓存。

## 验证

后端 Jest 覆盖 gzip 流、国家/年份/中方案过滤、单位换算、负净迁移、缺失单元格、网络失败、重复行、CSV模式变化、版本与情景限制，以及完整1208条链路和缺少一国年份时的部分完成状态。类型检查和生产构建也需通过。

真实文件抽查：中国1950年人口544044358人、净迁移-20646人；美国1950年人口154202680人。两国×151年×4指标应为1208条，图表与导出使用同一归一化结果。
