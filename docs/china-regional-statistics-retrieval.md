# 上海、北京年度经济数据检索记录

## 查询目标与口径

查询对象为上海、北京，年份为 2000–2025，目标字段为地区生产总值（GDP）、货物进出口总额及进出口总额/GDP。比值定义为：

```text
进出口总额占GDP比重（%） = 进出口总额 ÷ 同年GDP × 100
进出口总额 = 进口额 + 出口额
```

分子、分母必须使用同一币种和同一金额单位。比值是按名义现价金额计算的开放度指标，不是贸易差额（出口减进口），也不是增长率。国家统计局表格若缺少“进出口总额”，只有进口和出口时才相加；缺失值不能按 0 处理。

## 查询步骤

1. 从国家统计局国家数据入口进入分省年度数据：<https://data.stats.gov.cn/>。将地区分别设为北京、上海，按年度查 GDP 和进出口相关指标，核对数据表标题、指标解释、单位及统计范围。
2. 按地区和年份逐格整理源值。不要把全国值、城市统计公报摘要、同比增速或美元口径的世界银行数据混进地区年度序列。
3. 将 GDP、进口额、出口额统一为同一人民币单位，计算进出口总额与占 GDP 比重，并保留原始值、来源页面、指标名称、单位、查询时间和计算公式。
4. 检查年份覆盖：每座城市每项原始指标应覆盖 2000–2025 共 26 年；派生比值只在同年 GDP 与贸易数据均有效时计算。逐地区报告缺失年份，不用其他来源猜补。
5. 复查首尾年份、单位换算及比值抽样；如国家数据站未公开某年份或接口不可访问，应明确标为待核验。

## 项目侧改进

多地区 GDP 与贸易序列现在会确定性地产生国家统计局域名检索任务：每个地区拆成两个年份段，并把 GDP、进出口总额及派生比值分别登记为覆盖需求。相同域名下不同查询会保留，避免只执行该站点的一条查询。该改进让检索目标更明确，但搜索结果仍需按上述步骤核验，不能替代结构化数据 API 或数据表逐格验证。
