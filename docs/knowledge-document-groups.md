# 用户知识库文档分组

知识库详情页支持新增、重命名、删除文档分组，以及通过文档编辑选择所属分组。分组以知识库为范围，只有该库创建人可以修改。上传、自定义文本及资料存入弹窗均读取目标库的分组。

系统字典 `knowledge_group` 继续提供初始选项。用户重命名或删除预设时，只覆盖当前知识库的显示，不修改全局字典。重命名保留分组编码和文档归属；删除分组会在同一事务内将该库相关文档移到“未分组”，不删除文件或学习结果。文档写入与分组管理共用库级行锁，防止删除后写回失效分组。

## 接口

接口均要求用户登录，沿用现有响应封装。

| 方法 | 路径 | 参数与结果 |
| --- | --- | --- |
| GET | `/user/knowledge/groups?libraryId={id}` | 指定库须有存入权限；返回 `{code,name}[]`。省略 libraryId 时保留全局字典选项接口兼容性。 |
| POST | `/user/knowledge/libraries/{id}/groups` | 请求 `{name}`，返回 `{code,name}`，编码由服务端生成。 |
| PUT | `/user/knowledge/libraries/{id}/groups/{code}` | 请求 `{name}`，返回更新后的 `{code,name}`。 |
| DELETE | `/user/knowledge/libraries/{id}/groups/{code}` | 返回 `{movedCount}`，表示移至未分组的文档数量。 |

名称去首尾空格后为 1–64 个字符，同一库内不允许同名（忽略大小写），不可使用“全部文档”“未分组”。无权限返回 403；同名返回 409；无效名称或文档分组返回 400；编辑不存在的分组返回 404。
